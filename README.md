
# Obsidian + gruvbox

This is a [gruvbox](https://github.com/morhetz/gruvbox) theme for [Obsidian](https://obsidian.md).

## Code-highlighting-only snippet

This fork includes `gruvbox-code.css`, a CSS snippet that applies the Gruvbox
palette only to code highlighting. It styles CodeMirror tokens in Live Preview,
Prism tokens in Reading View, fenced code-block backgrounds, and inline code.
The rest of Obsidian keeps the selected base theme and appearance settings.

To install it, copy `gruvbox-code.css` to `.obsidian/snippets/` in a vault and
enable `gruvbox-code` under **Settings → Appearance → CSS snippets**. Do not
select the full "Obsidian gruvbox" theme if you only want code highlighting.
